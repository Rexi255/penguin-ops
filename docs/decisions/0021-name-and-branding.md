# 0021. Name and branding: PenguinOps

- Status: Accepted
- Date: 2026-11-16
- Supersedes: –

## Context

The repository was created as `penguin-ops`. The name should work in German and English and
signal "Linux" and "administration". A name check was done on 2026-11-16.

## Decision

- Game title: **PenguinOps**. Technical identifier: `penguin-ops` (repository, packages, app id).
- "Linux" is not part of the name (it is a registered trademark); descriptive use such as
  "a Linux learning game" is fine.
- The logo shows an own penguin, not Tux. Claude drafts it as SVG; the owner decides.
- "Sudo Ergo Sum" (a pun on "cogito ergo sum") becomes the name of the achievement for the
  first `sudo`.

Name check results: no game or software product named PenguinOps was found. The name is used
by a UK operations consultancy, a Japanese company and a YouTube gaming channel, all in other
fields. GitHub has only a few tiny repositories with this name; the npm name is free.

## Alternatives considered

- **Sudo Ergo Sum** as the game title: unique and witty, but beginners only understand the joke
  in chapter 6.
- **Rootine:** more than 100 GitHub repositories use it.

## Consequences

- Search results also show the unrelated companies; acceptable for a hobby project.
